# Backup Labs — écrans

| Écran | Rôle |
|---|---|
| Accueil | Bandeau d'état (« Tout est protégé »), sauvegardes avec la frise des 14 derniers passages, derniers passages, applications non protégées |
| Sauvegardes | Liste ; fiche d'une sauvegarde : lancer, mettre en pause, copies de sécurité, historique |
| Nouvelle sauvegarde | Assistant en 3 questions : quoi (applications, Plex, dossiers, clé Unraid), où, quand ; options avancées repliées ; récapitulatif en une phrase |
| Restaurer | Assistant : quoi, quelle version, tout ou une sélection, à côté ou à la place ; « seulement la base Plex » ; suivi en direct |
| Historique | Tous les passages ; détail d'un passage (applications, dossiers, copies) |
| Emplacements | Liste ; ajout : autre machine Backup Labs (code d'appairage), dossier, SMB, SFTP, rest-server ; bouton « Réveiller » |
| Alertes | Canaux ntfy, événements, test |
| Kit de secours | Téléchargement chiffré ou en clair du document de récupération |
| Réglages | Mode clair, sombre ou automatique ; version |
| Mises à jour | Version installée, puis les notes de chaque version (la plus récente d'abord) ; ouverte depuis la version affichée en bas du menu |

Menu : bloc de marque (logo, `backup.labs`, « Sauvegarde pour Unraid »), puis
Accueil, et trois groupes : **Protéger** (Sauvegardes, Emplacements),
**Récupérer** (Restaurer, Historique, Kit de secours), **Système** (Alertes,
Réglages). Icônes Lucide au trait de 1,75. En bas : la version de l'appli (un
point signale des notes non lues) et « Se déconnecter ».
