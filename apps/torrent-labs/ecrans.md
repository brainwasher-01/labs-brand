# Torrent Labs — écrans

| Écran | Adresse | Rôle |
|---|---|---|
| Recherche (accueil) | `/` | Champ `search>` ; résultats affichés en direct, indexeur par indexeur, avec barre de progression ; filtre par type (films, séries, livres…), filtre texte, choix des trackers ; ligne dépliable (détails, liens) ; bouton **grab** |
| Envoi vers qBittorrent | fenêtre sur `/` | Catégorie et tags (avec suggestions venues de qBittorrent), « en pause » ; confirmation vérifiée |
| Réglages | `/settings` | Prowlarr (adresse, clé), qBittorrent (adresse, identifiants), valeurs par défaut ; bouton « test connection » pour chacun |
| Journal | `/logs` | Onglets recherches et envois : date, nombre de résultats, durée, état (réussi, partiel, échec) |
| Connexion | `/login` | Compte unique |
| Premier lancement | `/setup` | Création du compte administrateur |
