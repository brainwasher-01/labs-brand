# Finance Labs — écrans

| Écran | Rôle |
|---|---|
| Connexion | Identifiant et mot de passe ; aucune page accessible sans connexion |
| Vue d'ensemble | Patrimoine, dernier mois importé, répartition (anneau), soldes par titulaire, revenus et dépenses sur 12 mois (hors virements internes), épargne cumulée |
| Comptes | Comptes regroupés par banque et par titulaire, avec leur solde ; ajout et archivage |
| Fiche d'un compte | Solde, opérations (recherche, note, suppression), saisie manuelle, actions |
| Import de relevés | Glisser-déposer ou boîte de dépôt surveillée ; fichiers à traiter, historique des imports avec les lignes non importées |
| Traiter un relevé | Lecture du fichier, réglages de lecture CSV mémorisés par banque, compte de destination, aperçu avec doublons grisés |
| Simulateur | Épargne dans X années (courbe versé / capital), atteindre un objectif, mensualité d'un prêt |
| Réglages | Banques, titulaires, réglages de lecture CSV, base et sauvegardes |
