# Projet Labs — écrans

| Écran | Rôle |
|---|---|
| Accueil | Bandeau d'état de la sauvegarde, projets par groupe (Labs, Crate, Infra, Perso), activité récente (badge Claude / Vous / Auto) |
| Projet | Points de restauration (« Restaurer »), chronologie des versions (« Changements », « Revenir ici »), export ZIP |
| Note | Onglets Lire (Markdown, liens `[[…]]`, sommaire, rétroliens), Éditer (aperçu, Ctrl S), Historique (changements, restaurer une version) |
| Recherche | Ctrl K : projets et contenu de toute la base |
| La suite Labs | Applis de la suite d'après `catalogue.json` : logo, nom, rôle, état, couleur, liens vers les chartes ; points de cohérence ; propositions |
| Connexion Claude | Adresse du connecteur, instructions à coller dans les projets Claude, sauvegarde, export |
| Connexion | Mot de passe de l'interface |
