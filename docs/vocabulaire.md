# Vocabulaire

Écrire pour quelqu'un qui n'est pas informaticien.

## Règles

- Phrases courtes, à l'infinitif ou à la deuxième personne du pluriel.
- Un mot par idée, le même partout dans l'appli.
- Les noms techniques (chemins, commandes, identifiants) en police mono.
- Les messages d'erreur disent ce qui s'est passé **et** quoi faire.

## Glossaire commun

| Éviter | Dire |
|---|---|
| job | tâche, ou le nom métier (« sauvegarde ») |
| run, exécution | passage |
| scheduler, cron | « chaque nuit à 3:00 », « chaque dimanche » |
| repository, destination | emplacement |
| snapshot | version |
| retention policy | combien de versions garder |
| token | code d'accès |
| pairing | relier |
| settings | réglages |
| dashboard | accueil |

Chaque appli complète ce glossaire dans `apps/<appli>/README.md`
(section « Vocabulaire propre »).
